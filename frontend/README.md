# SkillTrack Frontend

Angular application that consumes the `SkillTrack.API` backend.

This folder is intentionally empty for now — the Angular workspace (`ng new`) will be
scaffolded in its own step once the backend has real endpoints to talk to (starting
with authentication), so the frontend can be wired up against a working API from day
one instead of being built in isolation.

Planned stack: Angular, TypeScript, Reactive Forms, Router, HttpClient, Route Guards,
HTTP Interceptors, Bootstrap (or similar) for UI.
